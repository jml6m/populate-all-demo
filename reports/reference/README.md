# Reference benchmark reports

This directory holds the **canonical, source-controlled benchmark reports** for each official tagged release of the experiment.

## Layout

- Organize canonical artifacts by release version: `v1/`, `v2/`, ...
- Once a version directory is published, it is immutable and must not be modified.
- Unofficial/local run artifacts belong in the sibling gitignored path: `reports/local/<run-id>/`.

Reference contents in this directory begin with the `v1` release.
